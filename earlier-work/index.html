2023 – 2024 · Design foundation

Before growth, there was the interface.

Two internships in Figma, both about structure rather than decoration. They are the reason I can redesign a page and not only audit one.

2024 · Tuni’AR · Remote internship

Wash and Go, a mobile app.

UX/UI designer and graphic designer. I restructured the services and user profiles so the experience was easier to navigate.

  1. User flows. Mapped how someone books and tracks a service.
  2. Wireframes. Structure agreed before any visual design.
  3. Interface structure. Services and user profiles reorganised for clarity.
  4. Visual design. Consistent interaction patterns across screens.

2023 · TANIT WEB · On-site internship

A company website, restructured.

Web designer. I supported the redesign of the company website, working on research, wireframing and prototyping.

  1. Research. Understood what the existing site was failing to communicate.
  2. Wireframing. Clearer page structures before visual decisions.
  3. Prototyping. More intuitive navigation, tested as a prototype in Figma.

The thread

Same instinct, bigger surface.

Both internships were about making structure legible before making it pretty. On Worku that same instinct simply applied to a whole product, and to Google as well as to people.
